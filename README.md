# 此刻 · 世界时间

一个以北京时间为基准的世界时间对比与时区换算网页。支持 UTC、迪拜及浏览器提供的全部 IANA 时区，并会自动处理夏令时。

## 功能

- 实时显示北京时间和常用城市时间
- 搜索并筛选全球时区
- 对比各时区与北京时间的时差
- 按指定日期和时间进行时区换算
- 12 / 24 小时制切换
- 桌面端和移动端响应式布局

## 环境要求

- Node.js `20.19+` 或 `22.12+`
- npm `10+`

## 安装依赖

项目包含 `package-lock.json`，推荐使用：

```bash
npm ci
```

如果正在修改依赖，也可以使用：

```bash
npm install
```

## 本地开发

```bash
npm run dev
```

终端会显示本地访问地址，默认通常为：

```text
http://localhost:5173
```

## 生产构建

```bash
npm run build
```

构建完成后，静态文件会生成在 `dist/` 目录中。可以将这个目录部署到任意静态网站托管服务。

## 预览生产构建

先执行构建，再启动本地预览服务器：

```bash
npm run build
npm run preview
```

## 项目结构

```text
src/
├── components/    页面组件
├── lib/           时区数据与换算逻辑
├── App.jsx        应用入口组件
├── main.jsx       React 挂载入口
└── styles.css     全局样式与响应式布局
```

## 技术说明

- React + Vite
- 时区计算完全在浏览器中完成，不依赖后端或外部时间 API
- 时区列表来自浏览器的 IANA 时区数据，实际数量可能因浏览器版本而略有差异
